# Dataset github_gold originale

Questa cartella contiene il dataset github_gold di partenza, dal quale sono stati estrapolati il dataset di train originale train_github.csv e il dataset di test test_github.csv, tramite lo script split_dataset.py.
E' presente la cartella dataset_exloration che contiene i risultati dell'analisi esplorativa fatta sul dataset originale, usata per avere indicazioni utili su come generare i prompt.

## Contenuto
- github_gold.csv
- split_dataset.py
- analisi_esplorativa.py ---> script di analisi
- dataset_exploration/ ---> cartella che contiene i risultati dell'analisi esplorativa
