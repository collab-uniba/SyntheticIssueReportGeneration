# Datasets

Questa cartella contiene tutti i dataset utilizzati per gli esperimenti:

- train_github.csv ---> dataset train originale ottenuto dal 70% del dataset di partenza
- train_fewShot.csv ---> dataset train sintetico generato con tecnica fewShot con temperatura 0.8 (standard)
- train_fewShot_0.4.csv ---> dataset train sintetico generato con tecnica fewShot con temperatura 0.4
- train_fewShot_1.2.csv ---> dataset train sintetico generato con tecnica fewShot con temperatura 1.2
- train_fewShot_combined.csv ---> dataset train generato combinando il dataset originale (60%) con il dataset fewShot standard (40%)
- train_zeroShot.csv ---> dataset train sintetico generato con tecnica zeroShot con temperatura 0.8 (standard)
- train_zeroShot_0.4.csv ---> dataset train sintetico generato con tecnica zeroShot con temperatura 0.4
- train_zeroShot_1.2.csv ---> dataset train sintetico generato con tecnica zeroShot con temperatura 1.2
- train_zeroShot_combined.csv ---> dataset train generato combinando il dataset originale (60%) con il dataset zeroShot standard (40%)
- test_github.csv ---> dataset test ottenuto dal 30% del dataset di partenza
