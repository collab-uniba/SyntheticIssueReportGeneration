# SyntheticIssueReportGeneration - Setup

Nel repository sono presenti le due cartelle che contengono il lavoro sperimentale fatto con dataset StackOverFlow e GitHub.
Il contenuto comprende anche il necessario per la creazione del virtual environment apposito.

## Contenuto repository:
- Cartella esperimento StackOverFlow
- Cartella esperimento GitHub
- setup.sh --> script per la creazione del venv e per testare il corretto funzionamento dell'intero setup
- requirements_locked.txt
- test_gpu.py --> script per testare il corretto funzionamento e setup della gpu
- test_langfuse.py ---> per verificare l'avvenuta connessione
